# README_PARA_PRISM

Archivos para subir a Prism y su uso:

- INFORME_HALLAZGOS_PARA_PAPER.md: resumen ejecutivo y recomendaciones textuales.
- METODOLOGIA_Y_CALIDAD.md: fuentes, unidades, criterios, calidad y reproducibilidad.
- tablas/turnos_largos_por_semana_the_box.csv: evolución de horarios largos en The Box.
- tablas/dotacion_por_tienda_y_semana.csv: dotación por tienda y semana.
- tablas/auditoria_cruce_horarios_ventas.csv: auditoría del cruce.
- tablas/resultados_cruce_s34.csv: cruce exploratorio para la semana 34.
- tablas/encuesta_calificacion_atencion.csv: distribución de la calificación de atención.
- tablas/encuesta_temas_comentarios.csv: temas de comentarios clasificados.
- figuras/turnos_largos_the_box.png: evolución de turnos largos.
- figuras/dotacion_por_hora_tbrbsb_s34.png: dotación programada por hora.

Todos los archivos excluyen datos personales y se usan en agregado.
